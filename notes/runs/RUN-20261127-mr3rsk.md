  `recurringEventId` and `originalStartTime`) and its cancelled instance as a stub: status

  back the series: its master and every exception, the ones from before the token too,

  it, the moved instance confirmed with it. The newest token's listing is empty.

- `If-Match` with a stale ETag: 412 on `update` and `delete`, the event unchanged; with
  the current ETag both succeed.
